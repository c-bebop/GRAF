# About GRAF

GRAF (Graph Representation and Algorithm Framework) is my.. or one could say a
c++ programmers approach to writing a graph library in Rust. My main interests
are to implement graph data structures for file and memory I/O as well as graph
algorithms that perform well using multi-threaded environments.

Since this project is very much a WIP as well as a playground: please refer to
the implementation for documentation.. for now. 

## Motivation, Inspiration and Prior Work

The author's interested, motivation, and approach to graph data structures and
random-walk algorithm implementations in GRAF is shaped by prior research at the
Humboldt-Universität zu Berlin, published in [*ScaleRunner: A Fast
MPI-Based Random Walk Engine for Multi-CPU
Systems*](https://link.springer.com/chapter/10.1007/978-3-031-99872-0_9#citeas)
and realized in the C++ projects [ScaleRunner](https://github.com/hu-macsy/ScaleRunner) and
[graph-ds-benchmark](https://github.com/hu-macsy/graph-ds-benchmark). 

GRAF is an independent personal project; it is not affiliated with
Humboldt-Universität zu Berlin and does not derive from that institutional work.
